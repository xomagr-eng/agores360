# ΑΓΟΡΕΣ 360°

Offline web εφαρμογή σύγκρισης τιμών σούπερ μάρκετ & λίστας αγορών νοικοκυριού.

- 🔍 **Σύγκριση τιμών** σε πολλά σούπερ μάρκετ (καλύτερη τιμή + τιμή/μονάδα €/kg, €/L)
- 🏠 **Τι χρειάζεται ένα σπίτι** — λίστες βασικών ανά χώρο (κουζίνα, μπάνιο, υπνοδωμάτιο, καθαριότητα, ρούχα, εργαλεία…)
- 🛒 **Λίστα αγορών** με σύνολο κόστους ανά κατάστημα + «έξυπνο καλάθι»
- 📈 **Ιστορικό τιμών** (ανέβηκε/κατέβηκε)
- 📷 **Σάρωση barcode** (ζωντανή κάμερα ή φωτο) + φωτο απόδειξης για γρήγορη καταχώρηση
- 🌐 Κουμπιά για ζωντανή αναζήτηση σε e-Καταναλωτή, Skroutz, BestPrice
- 📱 Λειτουργεί σε υπολογιστή & smartphone · εγκαθίσταται ως εφαρμογή (PWA)

Άνοιξε το `index.html` (τοπικά με διπλό κλικ, ή μέσω https για πλήρη PWA/κάμερα στο κινητό).

Όλα τα δεδομένα αποθηκεύονται τοπικά στον browser (localStorage) — καμία αποστολή στο internet,
εκτός από την προαιρετική αναζήτηση ονόματος barcode μέσω Open Food Facts.
